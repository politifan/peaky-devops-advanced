Просмотренный план меняет только свои ресурсы

Все команды из корня ~/advanced-lab, кроме явно указанного cd.

umask 077
mkdir -p .runtime evidence
ssh-keygen -t ed25519 -f "$PWD/.runtime/ansible-key" -C dva-course
printf 'public_key_file = "%s"\n' "$PWD/.runtime/ansible-key.pub" > infra/local.tfvars
terraform -chdir=infra init
terraform -chdir=infra validate
terraform -chdir=infra plan -var-file=local.tfvars -out=../.runtime/create.tfplan
terraform -chdir=infra show -no-color ../.runtime/create.tfplan
terraform -chdir=infra apply ../.runtime/create.tfplan
terraform -chdir=infra output -json nodes

При генерации ключа задайте passphrase и используйте ssh-agent; вариант без passphrase допустим только для приватной изолированной лаборатории. Не переписывайте имеющийся ключ. Опция -chdir меняет рабочий каталог Terraform: ../.runtime ведёт в runtime корня. Применяйте файл только после просмотра сети, двух контейнеров, отдельных томов и loopback-портов. Код plan -detailed-exitcode: 0 — нет изменений, 2 — есть изменения, 1 — ошибка. State и plan не являются копией пользовательских данных.

Остановка при ошибке: запишите ненулевой exit code и последнее успешное наблюдение. Проверьте цель и причину, исправьте один фактор, повторите операцию новым именем evidence. Не удаляйте данные ради зелёного результата.
Дополнительные эксперименты и критерии каждого урока приведены в Stepik; общая подготовка выше выполняется один раз, а не повторно на каждом уроке.

Итог  передаваемая система
Исходная точка — принятие модулей 1–10, не новое внедрение по памяти. Подготовить repository с Terraform/Ansible, chart, Python приложением/миграциями/проверками, workflow, мониторингом и recovery. Не включать runtime/credentials/state/dumps. Закреплённые locks и provider lock включить, CI links и отчёты приложить отдельно.
1. Контракт: границы dev/stage, полезная операция, версия образа, SLO и окно, RPO/RTO, ограничения одного хоста; указать условия измерения.
2. Поднять стенд из чистого learner checkout по README. Terraform state не переносить как универсальное описание; другой человек создаёт свои ресурсы на отдельной Ubuntu. Фактические tool/image версии записать.
3. Ansible: fingerprints/inventory, два узла, повторный recap и HTTP. Kubernetes/Helm: UID namespaces/PVC, probes, успешный upgrade, прежние данные.
4. CI: доверенная main, hashed locks, зелёные Python+PostgreSQL проверки, image manifest/digest, dev→stage; отдельно красный build с отсутствием stage изменения.
5. Отказ A: удалить один stage API Pod при работающей DB, сохранить последовательность запросов и исправление. Отказ B: остановить stage DB; записать клиентские неуспехи, firing, dev при этом работает; вернуть DB и старую запись.
6. Backup/restore: отдельный namespace/PVC, полный SQL diff, old HTTP, post-copy missing event до новых записей, фактические RPO/RTO и место хранения копии.
7. Одна нагрузочная гипотеза: 3+3 серии, контроль условий, подтверждение либо опровержение.
8. Независимый оператор повторяет инструкции без доступа к вашей памяти; каждый непонятный шаг фиксируется, README исправляется и проблемный шаг повторяется.
Нельзя закрывать проект по числу YAML или сумме зелёных значков. Минимальные обязательные доказательства: полезная запись/чтение/изменение, тот же checked digest в dev/stage, отрицательная проверка доступа, исправление обоих отказов с прежними данными, восстановление отдельного экземпляра, протокол второго оператора. Пока второго человека нет, статус «передача не проверена».
Для демонстрации показать manifest/run links/HTTP/данные/alert timeline. Все аварийные действия описывать по точным именам своих ресурсов, не выполнять общую очистку томов. Итоговая рубрика в модуле 11, 100 баллов, зачёт 80 + все обязательные критерии. Шаблон сдачи в DOCX комплекте student.

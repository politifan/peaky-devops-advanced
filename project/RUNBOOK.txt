Передать воспроизводимый результат другому оператору

Все команды из корня ~/advanced-lab, кроме явно указанного cd.

git rev-parse HEAD
git status --short
git diff --check
kubectl --context kind-dva-course -n stage get deployment,service,pvc
./lab http --base http://127.0.0.1:18230 --out evidence/handoff.json

Составьте README с проверенными версиями, предпосылками, запуском, схемой зависимости и возвратом. Второй оператор должен собрать свою копию без вашего state, runtime и приватных паролей. Сверьте commit/образ, старые данные, отрицательную проверку и независимый restore. В финале выберите один из четырёх проектов, а не сдавайте все четыре. Дополнительные проекты могут расширить портфолио после обязательной защиты.

Остановка при ошибке: запишите ненулевой exit code и последнее успешное наблюдение. Проверьте цель и причину, исправьте один фактор, повторите операцию новым именем evidence. Не удаляйте данные ради зелёного результата.
Дополнительные эксперименты и критерии каждого урока приведены в Stepik; общая подготовка выше выполняется один раз, а не повторно на каждом уроке.
